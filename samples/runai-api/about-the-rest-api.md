## Sample

This sample introduces developers to the control-plane REST API before they begin making requests. It establishes what the API provides programmatic access to and connects those capabilities to practical integration scenarios such as workload automation, resource management, CI/CD integration, and multi-tenant administration.

The content is deliberately positioned before authentication and request mechanics so the developer first understands the API's purpose and mental model.
