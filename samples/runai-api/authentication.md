**Type:** Developer authentication guide

## Sample

This sample explains the bearer-token authentication flow used to access the REST APIs. It takes the developer from access credentials through requesting a temporary API token and then using the returned access token in subsequent API calls.

The published guide includes executable examples and the expected response, turning authentication from a conceptual prerequisite into an actionable developer workflow.
