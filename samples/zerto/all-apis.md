## Sample

This is a representative public sample of the REST API reference I worked on. The page acts as the API catalog: it organizes the available API surface by endpoint, subject, HTTP method, and purpose so developers can discover the correct resource before moving into endpoint-level documentation.

Representative entries include APIs for alerts, events, sessions, tasks, protected virtual machines, volumes, VPGs, virtualization sites, and other platform resources.

## What I owned

My API documentation work included working with Engineering and Product/QA through the API lifecycle, validating calls in Postman, reviewing requests and responses, resolving discrepancies, and translating verified behavior into developer-facing documentation.
