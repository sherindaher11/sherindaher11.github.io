# Protected VMs API — endpoint documentation sample

**Type:** REST API endpoint/reference documentation  
**My work:** API documentation and technical validation  
**Published source:** https://help.zerto.com/bundle/API.ZVR.HTML/page/Protected_VMs_API.htm

## Sample

This is a representative endpoint-level sample from the REST API documentation I worked on. The Protected VMs API documents the `/v1/vms` resource for retrieving information about protected virtual machines.

The published documentation covers the request URLs for all VMs, filtered VMs, and a single VM; the GET method; HTTPS/session authentication requirements; supported formats; request behavior; response examples; and the parameters and fields developers need to interpret the response.

## Validation workflow

I used Postman to exercise API calls and inspect requests and responses. When observed behavior and available engineering information did not align, I worked with Engineering and QA/Product to clarify the expected behavior before documenting it.
